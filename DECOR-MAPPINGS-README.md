# Справочник декоров УралПлит

## Как обновлять таблицу соответствий

**Основной файл для редактирования — `decor-mappings.csv`.** Сайт автоматически использует JSON, который генерируется из CSV.

1. Скачайте `decor-mappings.csv` и откройте его в Excel.
2. Сохраните резервную копию исходного файла.
3. Добавьте новую строку, измените нужные значения или удалите строку, которую нужно убрать из активного каталога.
4. Не меняйте названия колонок и порядок столбцов.
5. Сохраните CSV в формате UTF-8 с разделителем-запятой.
6. Загрузите обновлённый `decor-mappings.csv` в корень репозитория GitHub вместо старого файла. Можно открыть файл в репозитории, нажать редактирование и сохранить commit, если правок немного.
7. GitHub Actions проверит файл и автоматически обновит `decor-mappings.json`. После успешного запуска сайт опубликуется с обновлённым справочником.

Если проверка не пройдёт, прежний JSON останется на месте, а в разделе Actions появится ошибка с причиной. Скрипт не разрешит публиковать меньше 800 строк или строки без производителя/декора.

## Колонки

- `manufacturer` — производитель плит.
- `decor` — название декора ЛДСП.
- `edge` — соответствующая кромка УралПлит.
- `comment` — комментарий для клиента/менеджера.

Пустое поле `edge` допустимо, если соответствие ещё не подобрано. Для удаления из активного каталога удалите строку из CSV; исходную копию рекомендуется хранить отдельно.

## Остатки

Складские остатки обновляются отдельным автоматическим процессом и не редактируются в этом справочнике.
