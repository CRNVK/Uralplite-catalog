# Справочник декоров УралПлит

## Как обновлять таблицу соответствий

1. Скачайте `decor-mappings.csv` и откройте в Excel.
2. Сохраните резервную копию перед правками.
3. Для добавления декора добавьте новую строку; для изменения отредактируйте строку; для удаления уберите строку из активного списка.
4. На первом этапе пришлите мне отредактированный CSV: я проверю данные и обновлю JSON, который читает сайт. Автоматическую публикацию непосредственно из CSV можно добавить следующим этапом.

## Колонки

- `manufacturer` — производитель плит.
- `decor` — название декора ЛДСП.
- `edge` — соответствующая кромка УралПлит.
- `comment` — комментарий для клиента/менеджера.

Не меняйте названия колонок. Пустое поле `edge` допустимо, если соответствие ещё не подобрано.

## Остатки

Складские остатки обновляются отдельным автоматическим процессом и не редактируются в этом справочнике.
