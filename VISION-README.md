# Визуальный поиск декоров — прототип

## Что делает
- Принимает фото с камеры смартфона или из галереи.
- Сравнивает цветовые и текстурные признаки фотографии с эталонными миниатюрами.
- Показывает несколько визуально близких декоров, ссылку на источник и возможные соответствия кромки из `decor-mappings.json`.
- При наличии файла остатков пытается найти совпадения по названию кромки.

Это исследовательский MVP, а не обученная нейросеть. Результаты — визуальные кандидаты, а не доказательство производителя или точного декора. Свет, блики, угол съёмки и похожие рисунки влияют на ранжирование.

## Источники и обновление
На первом этапе подключены публичные страницы каталогов:
- NORDECO: https://www.nordeco.design/katalog-dekorov/
- Lamarty: https://www.lamarty.ru/lamarty/decors/plain.html

GitHub Actions запускает `scripts/sync_official_catalogs.py` по будням в 04:20 UTC (09:20 по Екатеринбургу) и вручную из Actions. Он проверяет страницы декоров, сохраняет URL источника и готовит небольшие JPEG-миниатюры в `vision/catalog-images/`.

Текущий охват зависит от того, какие страницы и изображения производитель отдаёт публично. Строка в каталоге без эталонного изображения не участвует в визуальном сравнении.

## Следующие шаги
1. Проверить результаты на реальных фотографиях и образцах.
2. Подключить официальные источники EGGER и Югра-Плит после проверки доступности каталогов и формата изображений.
3. Повысить качество распознавания: выравнивание баланса белого, выделение области плиты, более устойчивые признаки текстуры и оценка уверенности.
4. Проверить условия использования изображений у каждого производителя. Публичная доступность изображения сама по себе не означает разрешение на его копирование и коммерческое использование. До публичного коммерческого запуска следует получить необходимые разрешения либо использовать предоставленные производителями наборы данных на согласованных условиях.
5. Добавить ручное подтверждение результата и сбор обезличенной обратной связи о совпадениях.

## Структура записи `visual-catalog.json`
`manufacturer`, `decor`, `collection`, `description`, `image`, `source_url`, `image_source_url`, `source_checked_at`.
